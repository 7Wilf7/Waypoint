更新：2026-10-03，Asia/Shanghai。最新反馈要求删除奇怪背景曲线及文章叠线，恢复浏览中的标题入场与首屏互动。标题主体进入视野后完整播放；停滚或回滚不能停在半隐藏状态，阅读／键盘之后继续浏览也有入场，回顶部重看可再次触发。原范围继续保留：首屏夜间人像与舞狮合影、灰阶柔雾与背景滚动缩放、已有不重要小标和装饰环的弹性反馈、可替换背景音乐和悬停反馈。吴凡明确只迁移弹开的手感，不添加立体构件或 3D 框。正常浏览、无抽象山形、黑白灰、完整页脚和稳定的 Aevum 阅读预览继续保留。

## 体验路径

- 线上：[Waypoint](https://waypoint-wilf-wu.vercel.app/)，以最新成功的 Vercel 生产部署为准。
- 电脑：[本地预览](http://127.0.0.1:4173/)。
- 手机与电脑同一 Wi-Fi：[局域网预览](http://192.168.1.9:4173/)。地址随电脑网络可能变化。
- 本地重启：在 `site/` 执行 `WAYPOINT_HOST=0.0.0.0 npm run dev`；仅电脑验收可用 `npm run dev`。

1. 查看首屏：电脑文案与两张照片左右排布，手机上下排布；首图为夜间人像，约每 5.8 秒淡入切换。试上一张、下一张、暂停／播放、左右方向键与手机横向滑动；切语言保留当前照片和暂停状态。没有立体框、抽象山形或探索入口。
2. 在空白背景快速滑动鼠标：柔雾应跟随、晕开、漂移并渐消；扫过已有细标或创造区的装饰环，细节被弹开后回位。正文、链接、App 预览和它们的祖先保持原位。
3. 慢慢向下滚动：首屏两行文字有错层位移与轻微缩放，鼠标在首屏内移动有带阻尼的随动；上滑可逆。章节及卡片标题主体进入视野后以翻起、错位聚合、转入和上升等形式展开，说明文字逐渐点亮，卡片入场。标题开始展开时立刻停滚，约一秒内应完整显示；回滚一点仍保持全文，只有完整退到屏下后重新进入才重播。灰阶背景向下逐渐放大，向上回滚收缩；没有背景弧线、卡片同心线纹或文章标签双线。
4. 查看创造：在图标之间的灰底划动，作品展示面有水波反光；手机预览里的图像与文字保持稳定。在屏幕边缘外移动，尾迹也不能进入设备。试图片随动、Tab 随动和悬停箭头，再试四个 App 入口和内部热点。手机以正常点按与滚动为主。
5. 试右上角音乐开关：默认尝试低音量播放；浏览器拦截时首次点击启动。关闭后随便点击页面或刷新应保持关闭。阅读／隐藏页面暂停，返回时恢复先前选择。页脚可查看曲名、作者、许可与剪辑说明。
6. 打开赛记／项目：正文正常滚动，背景装饰停止；切语言、关闭、Escape 和浏览器返回均保留正常访问路径。关闭阅读后用鼠标继续向下滚动，尚未到访的标题应正常入场；用 Tab／PageDown 后切回鼠标也一样。当前正在阅读的标题不突然重新隐藏。
7. 切浅深主题，检查按钮悬浮、选中、按下与键盘焦点。刷新保留主题与语言；系统减少动态效果时停止装饰运动。
8. 用鼠标滚到真实页面底部，检查「下一站／留给好奇心」两行都完整出现；切语言或调整窗口高度后仍完整。此项不使用 End 键，以免键盘的直接显示逻辑掩盖滚动问题。
9. 悬停「沿途的坐标」，首张尚未准备好时有主题灰底和图片加载提示，准备好后完整显示；重复悬停复用已解码预览，快速切换不能显示上一场照片。打开比赛和赛事档案，横图、竖图、方图和长图都保持上传比例；点照片或「查看原图」可看完整原件。管理页三张预览同样保留比例，上传、保存、重开后不变。
