# Waypoint UI direction

更新：2026-10-11（Asia/Shanghai）。本文以吴凡最新反馈为准；内容定位见 [SITE-DIRECTION.md](SITE-DIRECTION.md)。

## Current decisions

- 采用正常浏览页面，按关于／山野／创造组织。取消探索模式、首次探索邀请、隐藏彩蛋及发现记录。
- 左上角与浏览器图标使用已有 Aevum 标志，站名仍为 Waypoint。复用 `aevum.center` 下的 `wilfwu` 子域名，直接指向独立个人站；登录、私有数据与 Aevum 应用保持各自边界。
- 首屏照片仅保留夜间人像与舞狮合影，移除原第一张及站内变体：电脑与文案左右排布，手机上下排布。照片保留原色。
- 背景增加为曜黑、雾白、深苔绿、岩灰四种，每种都有柔和光晕。右上角单按钮循环切换，当前与下一背景有双语提示；首页、赛事与管理页共享完整调色板和偏好，保留旧浅深主题选择。
- 动效与质感以 [Lusion](https://lusion.co/) 为参照，落实到正常页面的光照、材质、空间层次和连续反馈。保留原生滚动与可直接访问的内容。
- 最新要求进一步增加：柔雾鼠标痕迹、现有装饰元素受指针弹开后回位、安静的背景音乐、不同形式的滚动标题、随滚动放大／缩小和逐渐展开的背景，以及图片／Tab 随动和可点击标题的悬停提示。吴凡进一步澄清：只迁移弹开的交互手感，不把 Lusion 的立体构件或整块 3D 框搬进页面。
- 最新批注明确阅读优先：Aevum 手机预览屏不受任何水波、折射或尾迹覆盖，取消设备的装饰透视与光照。作品展示面保留互动；页脚必须在实际可达的页面底部完整展开。
- 删除背景弧线、比赛卡片同心线纹，以及文章标签周围叠加的分隔线；保留灰阶柔光、颗粒和文章之间的单层分隔。
- 标题、段落与内容面进入视野后自行完整入场；停滚或轻微回滚不能留在半隐藏状态。同一次可见停留内保持可读，完整退到屏幕上方或下方后再进入都可重播。首屏保留原生字距与排版，按整行轻移、淡入，不拆字翻转；阅读或键盘模式只临时显示全文，不消耗尚未浏览的入场。
- 所有标题与非点击内容获得带阻尼的鼠标推动及回位，正文与小标签位移更轻，文字仍可选择；可点击卡片仅推动标题文字，点击区域保持固定。首屏外层保留随动、滚动错层位移与轻微缩放，内层负责入场。App 预览设备、阅读器和控件保持稳定；手机以滚动反馈为主。
- 烟雾每一段按自身寿命扩散、淡出，停顿后续动与快速连续移动都不提前清空活烟雾；进入 App 预览时停止注入，其他区域的旧烟雾继续淡出，最终画面始终清除预览屏区域。
- 图片与作品展示区取消水波、荡漾及折射重绘，保留原图的清晰形状和已有轻微推移；烟雾与图片内容独立。
- 手机单指滑动增加轻量柔雾拖尾，松手后自然淡出；仅点按不产生柔雾，多指手势暂停。保留原生滚动与双指缩放，移动背景继续静态，App 预览、控件、阅读器与文字选择保持清晰稳定。
- 赛记和作品仍是已有内容，不新增真实经历，也不建立持续写作、想法或近况的更新义务。
- 赛事图片尊重上传形状：横图、竖图、方图和长图均保持完整比例，阅读、悬停与管理预览不裁切。保留原图，按预览／阅读尺寸提供清晰的轻量版本；临近视口提前加载，解码后显示，等待时使用主题灰底和双语提示。
- 赛事档案在鼠标悬停或键盘聚焦时并排预览主图、次图和完赛证书；点击仍向下展开同样三个位置，手机以点按展开。图片证书直接显示，缺失图片标注待补，旧 PDF 保留内嵌展示和兼容入口。返回个人网站时恢复离开首页时的滚动位置与入口焦点；直接打开档案则回到山野。
- 协作方式保留查看大图、播放／暂停和关闭，移除无效的二次放大按钮及其提示。
- 手机滑动柔雾提高可见度，单段寿命为 1.6 秒；扩大柔雾时同步计算绘制包围范围，保留原有像素上限、控件保护和空闲停绘。按压增加背景反馈，内容面入场位移由 44px 增为 56px，减少动态效果时保持稳定可读。移动背景继续静态；真机触感与性能单独验收。

## Motion and materials

| 表达 | 实现 |
| --- | --- |
| 大字与层次 | 首屏整行轻移、淡入，字距始终稳定，响应鼠标与滚动；关于标题翻起，山野文字聚合，创造标题转入，页脚展开；停滚、轻微回滚不打断，完整退到视口上下两侧后均可重播 |
| 首屏照片 | 两张用户提供照片，响应式 WebP，解码后淡入淡出；自动轮播、前后切换、暂停、键盘与横向触摸切换；照片内层轻微跟随鼠标，正文和轮播控制独立 |
| 赛事照片 | 自然比例与自动高度，竖图不塞进横框；私有轻量预览、高清阅读版、完整原图入口；悬停预热与解码结果复用，等待时有明确提示 |
| 弹性细节 | 标题、非点击正文、标签与图像受指针速度／距离轻推，带阻尼回位；异步内容与语言切换后自动注册，选择文字时暂停；不增加立体构件或框，控件点击区域和 App 预览及其祖先保持固定 |
| 背景 | 黑、白、深苔绿、岩灰均保留柔光；精细悬停指针使用独立固定装饰层，首页滚动时缩放、旋转，切换时淡入淡出；触屏使用无接缝的静态页面渐变，随原生滚动移动，停止固定背景的连续变换和颗粒层绘制；正文和预览设备不缩放；不绘制背景曲线 |
| 滚动说明 | 段落逐词／字从弱色变亮，内容面上移展开；进入视野后完整播完，不要求继续滚动；不额外绘制分隔线 |
| 材质 | 中性金属文字反光、磨砂表面、程序生成细颗粒、玻璃与边缘高光 |
| 统一光照 | 内容表面的柔光随指针连续变化，作品面有缓慢反光变化 |
| 全页鼠标 | 空白与展示区注入软雾团，随移动卷动、扩散、漂移、渐消；暂停和恢复不清空旧烟雾，按寿命控制采样容量；烟雾柔化／合成之后清除 App 设备区域，不绘制水波 |
| 手指滑动 | 首页与赛事页使用独立 2D 柔雾，经过位移门槛后按单指坐标采样，各段自然淡出；被动监听、不阻拦滚动与缩放；多指暂停到全部松开，保护当前坐标下的 App 与控件；限制绘制像素、只清理局部，不随地址栏高度变化重建画布 |
| 图片交互 | 图片不做折射或水波重绘；已有轻微推移与轮播继续使用原图，预览截图保持稳定清晰；效果层不接管点击、alt 或 App 热点 |
| 空间深度 | Aevum 产品展示有轻微透视、滚动位移与可打断的指针视差；界面导览保持稳定 |
| 连续反馈 | 导航指示、磁性按钮、悬浮阅读预览、按下反馈与阅读器转场沿用一致节奏 |
| 悬停提示 | 可点击文章、比赛、关于卡片标题出现下划线；Tab 标题浮出箭头并轻微跟手；键盘焦点同样显示提示，不把普通标题伪装成链接 |
| 背景音乐 | 从已选的八首 CC BY 4.0 录音中每次进入随机选一首，剪辑为安静循环；只加载当次选曲，页脚显示对应曲名、作者、来源与许可；低音量默认尝试播放，受浏览器限制时首次点击启动；可关闭且记忆开关，阅读／隐藏时暂停，切换语言与恢复播放不重新选曲 |
| 阅读与访问 | 阅读器、文字选择、隐藏页面、键盘和减少动态效果停止装饰运动；触摸仅触发独立轻量柔雾，不触发鼠标推动或桌面 WebGL；最后一段淡出后停止绘制 |
| 页面底部 | 页脚进入视野后自行完整展开，不依赖剩余滚动距离，两行文案不留在半隐藏状态 |

正常页面增加背景装饰层和已有细节的弹性反馈，没有可探索场景、地图或新立体构件。Aevum 保留原有四入口和真实界面演示；正文、比赛事实与公开／私有边界保持原状。手机以正常点按、滚动为主；减少动态效果保持稳定可读，WebGL 不可用时正常降级。

## Acceptance

当前改版需覆盖中英文、四种背景与跨页偏好、窄屏、键盘、减少动态效果、阅读与返回、文字选择、四入口导览、双向滚动重播，以及语言切换和异步内容后的动效重建。手指柔雾另需核对原生滚动、多指暂停、停顿后续动、App 与控件保护、地址栏尺寸变化和空闲停止；生产发布后核对线上资源和主要浏览路径。域名需解析与 HTTPS 验证后才算启用。手机真机触感与性能不能由桌面模拟替代。历史结果见 [体验验收记录](EXPERIENCE-ACCEPTANCE.md)，本轮证据留在忽略目录 `.local/verification/oct04-*`。
