# Waypoint UI direction

更新：2026-10-02（Asia/Shanghai）。本文以吴凡最新反馈为准；内容定位见 [SITE-DIRECTION.md](SITE-DIRECTION.md)。

## Current decisions

- 采用正常浏览页面，按关于／山野／创造组织。取消探索模式、首次探索邀请、隐藏彩蛋及发现记录。
- 首屏照片仅保留夜间人像与舞狮合影，移除原第一张及站内变体：电脑与文案左右排布，手机上下排布。照片保留原色，界面继续使用黑白灰。
- 主题恢复黑白灰。浅深主题、交互态与浏览器主题色全部使用中性灰阶；保存既有语言与主题偏好。
- 动效与质感以 [Lusion](https://lusion.co/) 为参照，落实到正常页面的光照、材质、空间层次和连续反馈。保留原生滚动与可直接访问的内容。
- 最新要求进一步增加：柔雾鼠标痕迹、现有装饰元素受指针弹开后回位、安静的背景音乐、不同形式的滚动标题、随滚动放大／缩小和逐渐展开的背景，以及图片／Tab 随动和可点击标题的悬停提示。吴凡进一步澄清：只迁移弹开的交互手感，不把 Lusion 的立体构件或整块 3D 框搬进页面。
- 最新批注明确阅读优先：Aevum 手机预览屏不受任何水波、折射或尾迹覆盖，取消设备的装饰透视与光照。作品展示面保留互动；页脚必须在实际可达的页面底部完整展开。
- 赛记和作品仍是已有内容，不新增真实经历，也不建立持续写作、想法或近况的更新义务。

## Motion and materials

| 表达 | 实现 |
| --- | --- |
| 大字与层次 | 首屏按行入场；关于标题向上翻起，山野文字错位聚合，创造标题转入，页脚上升展开；滚轮位置直接驱动进度，未完成时可前后调整，完成后保持完整可读 |
| 首屏照片 | 两张用户提供照片，响应式 WebP，解码后淡入淡出；自动轮播、前后切换、暂停、键盘与横向触摸切换；照片内层轻微跟随鼠标，正文和轮播控制独立 |
| 弹性细节 | 页面已有、不可点击且不重要的细标和装饰环受指针速度／距离推动，带阻尼回位；不增加立体构件或框，不推动正文、交互控件、App 预览或其祖先 |
| 背景 | 独立固定装饰层：深浅灰阶柔光、细颗粒和曲线；向下滚动逐渐放大并延展，向上回滚收缩；正文和预览设备不缩放 |
| 滚动说明 | 段落逐词／字从弱色变亮，内容面上移展开，章节线从左至右延展；停下滚动即保持当前进度 |
| 材质 | 中性金属文字反光、磨砂表面、程序生成细颗粒、玻璃与边缘高光 |
| 统一光照 | 内容表面的柔光随指针连续变化，作品面有缓慢反光变化 |
| 全页鼠标 | 空白与展示区注入有噪声层次的软雾团，随移动形成卷动、扩散、漂移、渐消；产品展示区域保留波纹，颜色沿用灰白；在全部柔化／合成之后清除 App 设备区域 |
| 图片交互 | 作品展示图片局部折射，小图标指针位移；轮播照片不进行 GPU 重绘，预览截图保持稳定清晰；效果层不接管点击、alt 或 App 热点 |
| 空间深度 | Aevum 产品展示有轻微透视、滚动位移与可打断的指针视差；界面导览保持稳定 |
| 连续反馈 | 导航指示、磁性按钮、悬浮阅读预览、按下反馈与阅读器转场沿用一致节奏 |
| 悬停提示 | 可点击文章、比赛、关于卡片标题出现下划线；Tab 标题浮出箭头并轻微跟手；键盘焦点同样显示提示，不把普通标题伪装成链接 |
| 背景音乐 | Kevin MacLeod《New Direction》经 CC BY 4.0 授权、剪辑循环并署名；低音量默认尝试播放，受浏览器限制时首次点击启动；可关闭且记忆选择，阅读／隐藏时暂停 |
| 阅读与访问 | 正文稳定；阅读、隐藏页面、键盘和减少动态效果停止装饰运动；离屏停止采样 |
| 页面底部 | 滚动时间线的终点限制在文档实际可达的滚动范围内，页脚两行文案不会因滚动空间不足停在半隐藏状态 |

正常页面增加背景装饰层和已有细节的弹性反馈，没有可探索场景、地图或新立体构件。Aevum 保留原有四入口和真实界面演示；正文、比赛事实与公开／私有边界保持原状。手机以正常点按、滚动为主；减少动态效果保持稳定可读，WebGL 不可用时正常降级。

## Reference evidence

本轮再次实际打开 Lusion，查看占满圆角框的立体交叉物、指针推开构件、背景缩放、滚动标题与声音开关。其素材、模型和音频没有复制；这里重新实现对应交互机制，并使用明确授权的独立音乐。静态截图与技术检查不能代表最终视觉认可。

此前三个保守示意方向与后来的数字山野均未获得最终视觉认可。尤其数字山野已由吴凡明确取消，旧文档中的探索规则不再是当前实现要求。

## Acceptance

当前改版需覆盖中英文、浅深主题、窄屏、键盘、减少动态效果、阅读与返回、四入口导览，以及语言切换后的动效重建。生产发布后还需核对线上资源和主要浏览路径。手机真机触感与性能不能由桌面模拟替代。具体结果见 [体验验收记录](EXPERIENCE-ACCEPTANCE.md)。
