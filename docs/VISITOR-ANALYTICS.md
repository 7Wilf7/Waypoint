# 访问统计

管理页新增「来访」面板：今日浏览、今日估算访客、近 7／30 天浏览与趋势、累计浏览，以及来源、设备、国家／地区、浏览器和页面概况。中英文和四种背景沿用网站偏好。统计失败、未连接与真实零访问分别显示；不会让内容管理等待统计服务。

## 统计口径与隐私

- 浏览量包括公开首页、主要栏目导航、赛事档案，以及实际打开的公开阅读。重复语言渲染不计数；切换到另一篇阅读会计数，但不发送文章标识或标题。它不是微信好友人数。
- 「今日」以 `Asia/Shanghai` 零点为界。独立访客为 Vercel 每日估算；不把每日 UV 相加冒充跨日独立人数。所有指标仅查询新版 `/visits/v2/` 路径，并在官方查询中排除已登记的浏览器标记。累计从新版采集上线重新开始，不包含旧版无浏览器标记的匿名汇总。旧数据仍留在 Vercel；不能声称已经认出或删除先前电脑、手机和微信的具体访问，也不从总量猜测扣数。
- 标记的是**同一站点域名下的浏览器存储环境**，不是整台物理设备。手机系统浏览器与微信内置浏览器互不读取对方的本站存储；不同浏览器、隐私窗口、电脑和不同域名也各自独立。各自在 `/manage` 登录后，初次默认开启「不统计我的访问」，将本浏览器已上报、尚待确认的新版随机标记登记为站主历史排除，并停止后续采集。管理页同步成功后才读取统计；主页不新增此开关。清除网站数据会丢失关联，即使以后重新登录，也无法恢复已经丢失标记的历史。
- 排除登记永久保留。管理页开启开关先停止采集，再同步历史；关闭开关必须先完成历史登记并清除当前采集标记，最后才恢复后续采集；新随机标记只在下一次允许采集时创建。已排除历史不会因为关闭或下一次登录而重新出现。显式关闭会保留这一选择；已登录期间仍始终不采集。同步失败保留待确认标记并显示可重试错误，不把失败当作清零，也不自动反复重试。容量满时继续显示服务端按既有排除生成的报告，并明确提示本浏览器历史尚未排除。
- 管理页及已登录的 owner 不上报；会话核验失败时也不上报。页面重新可见、窗口重新获得焦点或即将计入新的公开路由时先刷新身份，等待期间暂停统计，以覆盖在另一标签登录和内置浏览器缺少焦点事件的情况；不加定时心跳。首次会话读与原管理入口检查共用，此后的有效导航会多一次只读会话请求，匿名请求不读取 Blob；页面切换本身不等待它。隐藏页面待可见后才记录。
- 允许采集且能够持久保存标记时，浏览器生成随机 128 位标记（32 个十六进制字符），写入本站 `localStorage`。SDK 的 `requestPath` 为 `/visits/v2/<browser>/<source>/<page>`，`route` 为 `/visits/<source>/<page>`；前者支持历史排除，后者用于页面分类汇总。来源只允许 `direct`、`moments`、`wechat`、`other`，页面只允许固定栏目。标记随合成路径发送给 Vercel，不含真实身份、阅读 ID、标题、当前网址查询参数或 hash，也不在其他站点使用。入口来源只在当前页面生命周期内保留。普通访客停用统计、启用 Do Not Track 或 Global Privacy Control 时，先于标记创建拦截，不创建新标记或发送统计事件；站主登录仍可向本站登记已有标记，以排除历史。无法持久保存标记的访客不采集。
- 管理页「复制朋友圈链接」生成 `/?from=moments`。带标记链接转发后的访问也归入这一来源，不能证明每次访问真的发生在朋友圈。未标记的微信内置浏览器归入「微信内打开」；其它外部页面归入「其他来源」，不会展示个人来源 URL。
- 不要求微信登录，不显示昵称、头像、OpenID、个人访客列表或精确位置。不做跨站追踪。Vercel 本身仍会处理请求、来源页面、大致城市、系统和浏览器版本，并生成每日变化的匿名标识；本站面板仅展示国家级等汇总。不能把这描述为服务商完全不处理 IP、没有持久浏览器标记或只收集国家。站主排除只过滤管理页查询，**不删除 Vercel 原始记录**。
- 页脚「隐私与访问统计」披露上述随机标记，并保留普通访客的停用选项。浏览器保存访问偏好 `waypoint-analytics-opt-out`、排除偏好 `waypoint-owner-device`、当前随机标记 `waypoint-visit-browser`、各已上报标记的待确认键 `waypoint-visit-pending:<id>`，以及最近确认的当前排除标记 `waypoint-visit-excluded`。待确认键各自独立，避免多标签覆盖；服务端确认后才删除。普通停用保留已有标记，以便站主以后登录排除历史。普通访客的停用偏好与管理排除独立，管理页恢复统计不会清除隐私选择。任何浏览器偏好或随机标记都不能用于授予管理权限。

普通网页不能从朋友圈静默取得访客昵称和头像。认证服务号的 `snsapi_base` 可在微信规则允许的条件下静默取得 OpenID，仍不等于昵称／头像，也需要账号和授权域名等前提；`snsapi_userinfo` 涉及网页授权。本实现采用匿名概况和分享标记，没有接入微信 OAuth。

## 服务与启用

采用官方 `@vercel/analytics` 和 Web Analytics API，不对每次来访写入私有 Blob。统计接口 `GET /api/manage/analytics?days=7|30` 和登记接口 `POST /api/manage/analytics/browser` 先通过既有 owner 身份核验；随机标记和伪造身份头都不能代替登录。查询固定项目，浏览器不能选择项目、团队或任意时间范围。响应 `no-store`，服务端有 60 秒有界内存缓存；命中缓存也重新验证 owner，并读取最新排除列表及其版本，避免刚完成排除仍返回旧报告。

私有 `settings/analytics-exclusions.json` 保存有版本的排除标记列表，登记采用条件写入，只追加，不移除历史标记。报告的全部维度在服务商查询中应用完整排除；没有未过滤原始数据的回退路径，也不逐浏览器相减估算 UV。官方查询过滤器的长度限制使当前实现最多保存 **26 个排除标记**，不是 26 台物理设备；手动恢复采集后再次登录、重新标记或更换浏览器也可能增加数量。第 27 个新标记登记失败时，已有 26 个排除仍有效，新标记继续保存在浏览器待确认，后续本地采集保持停止；管理页显示容量错误及仍应用既有排除的报告，不能声称本次历史已清除。该限制不通过自动删除旧排除来规避，否则会让历史重新出现。

Vercel Hobby 当前包含每月 50,000 次团队共享事件、一个月明细窗口；达到免费额度后统计暂停，不自动升级或产生超额事件费用。本实现不依赖付费的 UTM 分组或 custom events。额度、版本及套餐应在实际启用时再次核对。

正式启用前须获准发布、启用项目 Web Analytics，并在 **Production 服务端环境**配置：

| 变量 | 用途 |
| --- | --- |
| `WAYPOINT_ANALYTICS_TOKEN` | 可查询该项目的 Vercel access token，使用合适的最小作用域和有效期；不把本机 CLI 凭据自动复制到部署 |
| `WAYPOINT_ANALYTICS_PROJECT_ID` | 固定的 `prj_…` 项目 ID |
| `WAYPOINT_ANALYTICS_TEAM_ID` | 团队项目的 `team_…` ID；个人项目可省略 |

这些值不会输出到前端。构建只有在 `VERCEL_ENV=production` 且 token／项目 ID 均已配置时才开启前端采集；本地和 Preview 默认关闭。SDK 也不会因为仅打开管理页就注入。缺少配置或项目未启用时，管理页显示「尚未连接」。凭据失效、限流、查询错误或无法可靠还原时间序列时显示读取失败，不伪装成零访问。

启用免费 Web Analytics 需要账号本人在控制台或交互终端确认；当前 CLI 的非交互模式会返回 `confirmation_required`。CLI OAuth 登录也不能创建查询令牌，实际调用返回 `403 Cannot create tokens for this app.`。应由账号本人在 [Access Tokens](https://vercel.com/account/settings/tokens) 创建仅限本项目的令牌，并保存到 Production 的 `WAYPOINT_ANALYTICS_TOKEN`，不要把令牌发到聊天、加入 Git 或替换为本机短期 CLI 凭据。

报告按小时分成不超过四天的片段，避免 API 的 100 行上限吞掉 30 天趋势；随后按广州日界汇总。其他维度取前 100 项，服务商的剩余项归入「其他」。每次查询都应用同一完整浏览器排除条件。排除登记读写私有设置，不读取内容目录，也不逐次保存访客明细。

今日和期间 PV 统一来自小时趋势；今日 UV 来自独立的每日范围查询。服务商没有跨查询共同快照保证，迟到数据可能让这些估算短暂不同步，不因此把正常报告判成失败。

部署沿用 [公开内容交付约定](PUBLIC-CONTENT.md)：重新核对当前主分支和生产配置，需要重新导出真实公开内容时先批准并暂停写入，不能把本地虚构数据或旧快照推上生产。

## 初版发布前验证记录（历史）

2026-10-10，发布授权前的只读核对显示：现有团队为 Hobby，项目 Web Analytics 尚未启用。以下为独立候选 worktree 的发布前验证，不作为正式发布成功或线上已连接的证明；正式状态须以本次部署和现场查询证据为准。

`npm run check` 覆盖 owner 权限、撤销会话后的缓存拒绝、日期边界、白名单路径、隐藏页面、关闭统计、DNT／GPC、计数错误和语言完整性。实际浏览器使用虚构数据验证桌面、320 像素窄屏、四主题、键盘明细、语言切换、加载失败、空数据、未连接、复制分享链接及退出时清除待返回数据。初版双标签复验确认另一标签登录后，原公开页有效导航不再增加记录；首版浏览器排除改版后退出也继续排除，仅在管理页显式恢复后才重新计数；这条记录不证明新版历史排除已完成验证。

官方 SDK 的实际上报被本地服务接收，已核对当前网址查询参数和阅读 ID 不进入负载。不同本地端口的外部来源复验中，浏览器默认来源策略仅传递来源 origin，SDK 的非空 referrer 保留该 origin；不能把这一样本推论为所有外部网站的 referrer 都会去除路径／查询。服务商可能处理来源页面，已经在页脚隐私说明中披露。

候选的本地证据保存在忽略的 `.local/verification/visitors/`，收尾时可归档到主 checkout 的 `verification/visitor-analytics-release/`。其中截图中的数字是虚构示例；不代表真实访客。发布前本地验证未覆盖成功的线上查询、自然访客数据、微信真机、Safari 和实体手机，不能据此宣称这些检查已通过。

## 新版历史排除的交付边界

本次新增的是可追溯的浏览器排除及管理页新口径，不把上面的初版截图、虚构数据或旧部署证据当作新版验收结果。交付时需要在整合后的代码核对：先匿名访问再登录能排除已关联历史；另一真实访客的访问保留；退出后仍停止采集；明确恢复采集后旧历史不复活；同步失败、存储受限、26 标记容量和退出后的迟到响应不误报成功；中英文、桌面窄屏、键盘及四种背景保持可用。实际发布状态和生产证据另行归档，不从候选代码提交推论已上线。微信、Safari 和实体手机需单独声明实际验证范围。
